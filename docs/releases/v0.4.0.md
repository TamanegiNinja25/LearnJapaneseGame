Tappable skills, varied suggestions, practice links in the exam, town sprint, and update notices.

## What's new

- **Update notices:** the game checks GitHub once at start and shows a popup when a newer version
  is out, with ダウンロード (the APK on Android), あとで, or このバージョンをスキップ. Turn it off in
  設定 › 起動時に更新を確認する. This is the game's only network request; the Android app now asks
  for the internet permission because of it.
- **Tap a skill to practise it:** every skill row on ホーム opens the activity that raises that
  skill.
- **Varied 次にやること:** after you start the same suggestion three times in a row, a different
  activity is suggested for a change (the stage exam is never swapped out).
- **Practice links in 試験:** the pass marks and the results show your score beside each skill with
  a 練習する button; skills below the pass mark are highlighted.
- **Town:** faster walking and running, a 走る sprint button on touch screens, and the left-stick
  click sprints on a gamepad.
- **Fixes:** answer buttons no longer overlap when a long answer wraps, and the furigana has room
  inside each button; the kanji grid wraps to the screen instead of running off the edge.
- Installs over v0.3.x on Android and keeps your progress.
