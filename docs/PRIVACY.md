# Privacy policy — 日本語の世界 (LearnJapaneseGame)

Last updated: 2026-11-21

日本語の世界 is a Japanese-learning game. It has no accounts, no ads, no analytics and no
tracking.

## What stays on your device

- **Your progress** (words, scores, settings, writing practice) is saved only on your device.
  It is never uploaded. Backups you make with 設定 › バックアップをコピー go to your clipboard,
  and you decide where to paste them.
- **Microphone:** the shadowing practice records your voice so you can play it back next to the
  model sentence. The recording stays in memory on your device, is never saved to a file, and is
  never sent anywhere. The microphone is used only while you record in shadowing practice.
- **Speech:** listening practice uses your device's own text-to-speech voice.

## The one network request

At start, the game asks GitHub whether a newer version has been released, by sending one request
to `https://api.github.com/repos/TamanegiNinja25/LearnJapaneseGame/releases/latest`. The request
contains no personal data and no identifiers; like any web request, GitHub can see your IP
address (see GitHub's privacy statement). You can turn this off in 設定 › 起動時に更新を確認する.
Nothing else is sent over the network, and the game works fully offline.

## Children

The game collects no personal data from anyone, including children.
